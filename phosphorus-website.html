Phosphorus Website Details

Phosphorus Cybersecurity's website is built on Wordpress using the Elementor page builder. There are many pages custom built using Webflow, HTML and CSS.

The Project

I was responsible for the complete redesign and rebranding of the company's website. At the outset, the site consisted of only a basic, generic layout with no visual direction or existing content to guide the process. I designed each page from the ground up, developing a fully custom, dynamic, and engaging user experience. Despite the challenges, I delivered a visually compelling website that continues to resonate with customers today.

As the webmaster, I was responsible for ensuring the website remained current with the latest design trends, functionality improvements, and technical updates. This role required continuous oversight and maintenance, all while I simultaneously served as the company’s Senior Digital Design Manager. Check out my work for more details.



Phosphorus Core Pages

The website was primarily built using the Elementor page builder, featuring fully custom-designed layouts. Each section includes tailored illustrations, imagery, or visual elements strategically designed to enhance and support the content, creating a more engaging and intuitive user experience.



Custom Pages

Several key pages—such as the Platform, Intelligent Active Discovery, and Global Device Network pages—were developed using Webflow, HTML, and CSS. These pages were custom-designed to deliver a visually striking experience while effectively engaging the audience through thoughtful layout, interactivity, and design.
