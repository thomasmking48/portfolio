Anitian Website Details

Anitian's website is built on Wordpress using the Divi page builder. There are many pages custom built using HTML and CSS.

The Project

I was responsible for the complete redesign and rebranding of the company's website. At the outset, the site consisted of only a basic, generic layout with no visual direction or existing content to guide the process. I designed each page from the ground up, developing a fully custom, dynamic, and engaging user experience. Despite the challenges, I delivered a visually compelling website that continues to resonate with customers today.

As the webmaster, I was responsible for ensuring the website remained current with the latest design trends, functionality improvements, and technical updates. This role required continuous oversight and maintenance, all while I simultaneously served as the company’s Digital Design Manager. Check out my work for more details.



Anitian Core Pages

The website was primarily built using the Divi page builder, featuring fully custom-designed layouts. Each section includes tailored illustrations, imagery, or visual elements strategically designed to enhance and support the content, creating a more engaging and intuitive user experience.


Designer Note


The website has not been regularly maintained since my tenure as webmaster. As a result, much of the original design and functionality has been lost. You can view the original version using the Wayback Machine for reference.
